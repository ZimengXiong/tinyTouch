# CLI copy review

A static review page for tinyTouch's CLI. Edit individual lines, add comments, and copy feedback into chat for manual implementation. The page does not change the CLI or send comments to a server. Drafts save in browser local storage for this catalog snapshot; feedback can also be downloaded as plain text.

The catalog includes evaluated interactive menus, settings, command help and argument error examples. Python source extraction includes nonempty runtime string literals and f-string templates, including literals inside template expressions. Installer output and tracked firmware C string literals are included. Each nonblank line has its own editable entry; repeated occurrences remain separate. Internal tokens and formatting strings appear in the technical appendix. External output boundaries identify text generated by macOS, subprocesses or changing device values. Docstrings and empty layout strings are excluded.

Rebuild from the repository root:

```sh
python3 tools/cli-copy-review/build.py
node --check tools/cli-copy-review/site/app.js
node --test tools/cli-copy-review/feedback.test.cjs
```

Generation imports the CLI's metadata and parses invalid arguments to capture error wording. It does not execute command handlers, connect to hardware, change device settings or import the native macOS helper modules.

Publish the static directory with Devshare:

```sh
~/.local/bin/devshare publish --keep tools/cli-copy-review/site
```

Use `--update SHARE_URL` to replace an existing share. The snapshot key keeps drafts separate when the catalog changes. Copy feedback before switching to a new snapshot.
