What’s included

Prompts, menus, notifications, errors, settings, enrollment instructions, installer output and generated help for every command. Each nonblank line is editable, including repeated occurrences in different contexts.

{value} marks a Python template value; %s and %d mark firmware values. Keep placeholders unless you want to change what the message includes. Some rows are pieces of a composed message; use comments to describe a change to the whole message.

The technical appendix contains the remaining runtime string literals from the CLI, helper, native support modules and tracked firmware C files. It includes command tokens, JSON keys and formatting strings that may appear in diagnostics. These are available for review but many also control behavior.

Operating-system prompts, external tool errors and changing device values are generated at runtime. Their output boundaries appear in “External and dynamic output”; their exact values cannot be enumerated here. Blank layout lines and code docstrings are omitted.

This is a manual review page. Edits do not change the CLI, and drafts are not shared across browsers. “Copy feedback” includes all edited or commented lines, regardless of the current filter.
