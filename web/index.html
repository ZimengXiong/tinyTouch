Set up tinyTouch

Built your own? Flash the firmware first. Devices bought from us are already flashed.

1. Install

curl -fsSL https://tinytouch.alpacaengineer.ing/install.sh | sh

This installs the correct CLI for Apple silicon or Intel.

2. Connect

Connect tinyTouch with a USB data cable.

3. Run setup

tinytouch setup

Choose PIV or HID. Setup enrolls four views of the same finger for more reliable touches.

For a Terminal password prompt, use your Mac administrator password. For a smart-card PIN prompt, use 000000.

Update

tinytouch update

Touch the sensor to authorize. You do not need to press BOOT.

Additional Macs

tinytouch add-computer

Run this on each additional Mac. It uses the device's current PIV or HID mode.

Check it

tinytouch test
tinytouch status

Other commands

tinytouch enroll
tinytouch pair
tinytouch mode piv
tinytouch mode hid
tinytouch factory-reset

If macOS blocks it

xattr -d com.apple.quarantine "$(command -v tinytouch)"
