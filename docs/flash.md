# Install firmware

Open this page in Chrome or Edge.

## 1. Connect the board

1. Disconnect USB.
2. Hold **BOOT** while plugging in USB.
3. Release **BOOT**.

## 2. Flash

Select **Factory firmware**, click **Connect and flash**, and choose the ESP32-S3 port.

<FlashTool />

When flashing finishes, unplug the board and plug it back in.
