- fixed the macos helper going quiet after usb reconnects and config commands
- cli commands now hand usb back to the helper without restarting it every time
- helper upgrades wait for launchd to finish stopping the old process and restore the old service if replacement fails
- password changes keep existing keychain access rules, and a failed write keeps your old password
- added `tinytouch password` and `tinytouch password --finger 2` for changing the default password or giving a finger its own
- fixed french accent sequences and croatian semicolon mapping; added `tinytouch keyboard-layout auto` and `tinytouch keyboard-layout us`
- hid setup checks this mac's password, pairing key, and host registration before saying it's ready, and can resume after reconnecting
- removed serial drain calls that could leave commands or ota uploads stuck
- usb resets cancel pending password replies and interrupted typing, including the final enter key
- fixed split ccid packets, exact-packet-size replies, and stale transfer state after usb resets
- factory reset keeps mac setup if device erasure fails and preserves smart-card pairings it can't match to the selected device
- partial fingerprint groups on smaller sensors can now be deleted, and enrollment checks capacity before replacing a finger
- added `tinytouch update --file signed-firmware.bin` to upload a local signed image through the normal usb ota path
- `tinytouch hid-smoke` now uses temporary secrets and leaves the installed helper and saved passwords alone
